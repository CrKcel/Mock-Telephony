# Mock Telephony 

![Platform](https://img.shields.io/badge/Platform-Android-brightgreen)
![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)

A KernelSU module that enables the telephony stack on Android tablets and registers a bootstrap Radio HAL.

For testing purposes only. Do not install on devices that have a baseband.

Designed to support Magisk/KernelSu/Apatch devices on Android 13+.

Only fully verified on Android 16 with KernelSU; may not work on other devices.

***

为安卓平板启用电话栈并注册 bootstrap Radio HAL 的 KernelSU 模块

仅供测试用途，请不要在有基带的设备上安装。

设计上支持 Android 13+ 的 Magisk/KernelSu/Apatch 设备。

但是仅在 Android 16 的 KernelSU 设备上进行过完整验证，其它设备上也许无法正常工作。
